Answer the question in the first paragraph, define metrics consistently, cite original sources beside claims, and add schema only when it describes visible content.

## Findability brief: product activation guide

- Search title: `Product activation: definition, metric, and examples`
- Reader outcome: identify one activation event and its measurement window.
- Required sections: definition, how to choose an event, worked example, limitations, next action.
- Internal links: activation event specification; guided demo.
- Do not promise a universal activation metric; state that the event depends on product value.
