# Data handling

| Classification | May enter an external AI tool? | Rule |
| --- | --- | --- |
| Public | Yes | Include source URL and checked date. |
| Internal | Only after product-marketing approval | Use aggregated metrics; remove customer names. |
| Restricted | No | Customer events, screenshots, credentials, and unreleased roadmap details never leave approved systems. |
