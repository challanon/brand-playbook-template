# Visual identity

| Token | Value | Use |
| --- | --- | --- |
| Northstar navy | `#14213D` | Headings and primary UI |
| Signal lime | `#C7F464` | Focus states and data highlights only |

Use Inter for body and Space Grotesk for headings. Imagery shows real working environments, natural light, and legible product detail. Use generous whitespace and simple data marks. Avoid neon gradients, anonymous stock-photo handshakes, and decorative charts without labelled scales.
