# Visual identity

| Token | Value | Use |
| --- | --- | --- |
| Northstar navy | `#14213D` | Headings and primary UI |
| Signal lime | `#C7F464` | Focus states and data highlights only |

## Semantic tokens

| Token | Value | Rule |
| --- | --- | --- |
| `color.text.primary` | `#14213D` | Use for long-form text; do not substitute lime. |
| `color.action.primary` | `#14213D` | Use for the primary CTA; one primary action per view. |
| `color.focus` | `#C7F464` | Visible keyboard focus only; maintain contrast against its surface. |
| `space.page.gutter` | `24px` | Minimum mobile page gutter. |

Use Inter for body and Space Grotesk for headings. Imagery shows real working environments, natural light, and legible product detail. Use generous whitespace and simple data marks. Avoid neon gradients, anonymous stock-photo handshakes, and decorative charts without labelled scales.

The machine-readable token sample is in [`assets/files/tokens.json`](files/tokens.json). Check colour contrast and keyboard focus before publishing a design.
