# Typed contracts

These schemas are optional Core extensions and required by the Production Profile. They are tool-agnostic: a runtime, agent framework, or CMS adapter maps them to its own API.

- `task-request` — caller intent and authorised scope
- `agent-result` — generated draft and evidence references
- `review-result` — pass/fail findings and approval requirement
- `publication-record` — CMS-agnostic handoff record
- `evidence-record` — source and claim provenance
- `policy-decision` — runtime authorisation decision
